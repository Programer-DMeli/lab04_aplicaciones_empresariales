# REQUERIMIENTOS FUNCIONALES DEL SISTEMA
# =============================================================================
#
# Módulo de Catálogo
#   RF-01  Registrar libros con título, ISBN-13, año, páginas y portada.
#   RF-02  Registrar autores con nombre, apellido, fecha de nacimiento y nacionalidad.
#   RF-03  Registrar editoriales con nombre, sitio web y dirección.
#   RF-04  Registrar categorías con nombre único y descripción.
#   RF-05  Consultar el catálogo completo de libros disponibles.
#   RF-06  Consultar el detalle de un libro: categorías, editoriales, autor y perfil.
#
# Módulo de Relaciones entre modelos
#   RF-07  Cada libro pertenece a un único autor (relación N:1 / ForeignKey).
#   RF-08  Cada autor puede tener como máximo un perfil detallado (relación 1:1).
#   RF-09  Un libro puede pertenecer a una o varias categorías (relación N:M).
#   RF-10  Un libro puede ser publicado por una o varias editoriales (relación N:M
#          con modelo intermedio), guardando fecha de publicación y número de
#          edición de cada una.
#   RF-11  Al eliminar un autor, sus libros y su perfil se eliminan en cascada.
#
# Módulo de Administración
#   RF-12  Gestionar autores, perfiles, libros, categorías, editoriales y
#          publicaciones desde el panel de administración de Django.
#
# Módulo de Consulta (ORM)
#   RF-13  Consultar en ambos sentidos de la relación (ida y vuelta).
#   RF-14  Filtrar registros atravesando relaciones con doble guion bajo (__).
#
# No funcional
#   RNF-01  Interfaz web responsive en español, sin JavaScript externo (CDN-free).
#   RNF-02  Validación de datos mediante constraints de base de datos (ISBN único,
#           unique_together en Publication, name único en Category).
#   RNF-03  Suite de pruebas automatizadas que cubre las relaciones y el
#           comportamiento de on_delete.
#
